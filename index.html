Módulo 1

O Núcleo do PHP

Uma imersão profunda nas regras de negócio e lógica de programação.

O que é o PHP na Prática?

Quando você acessa um site, duas coisas acontecem ao mesmo tempo: o que roda no seu computador (Client-Side) e o que roda no computador da empresa dona do site (Server-Side).

  • Client-Side (Navegador): Lê HTML, CSS e JavaScript. Pinta a tela, anima botões e responde ao clique do mouse. O usuário vê e interage aqui.
  • Server-Side (Servidor): É onde o PHP mora. Tem acesso ao Banco de Dados, verifica senhas, calcula preços e decide o que cada usuário pode ver. O resultado chega ao navegador já como HTML estático e seguro.

🔍 Por que aprender PHP?

Cerca de 77% de todos os sites do mundo usam PHP no servidor (WordPress, Wikipedia, Facebook usam PHP). Ele foi criado especificamente para a web, roda em qualquer hospedagem por menos de R$20/mês, e com o framework Laravel é uma das stacks mais contratadas do mercado brasileiro hoje.

Como rodar PHP no seu computador? Instale o XAMPP (gratuito). Ele cria um servidor Apache + MySQL + PHP na sua máquina. Depois, coloque seus arquivos .php dentro da pasta htdocs e acesse pelo navegador em http://localhost/seu_arquivo.php.

Variáveis, Regras e Tipos de Dados

Variáveis são espaços na memória do servidor para guardar dados temporariamente. Pense nelas como gavetas etiquetadas: você cria uma gaveta, escreve um nome na etiqueta e coloca algo dentro para pegar mais tarde.

As 3 Regras de Ouro das Variáveis

  1. Toda variável obrigatoriamente começa com cifrão $. Ex: $cliente.
  2. Variáveis não podem começar com números nem conter espaços. (✅ $nome1 | ❌ $1nome | ❌ $nome do cliente).
  3. PHP é Case-Sensitive: $Nome e $nome são variáveis completamente diferentes!
PHP

<?php
// ===== OS 4 TIPOS ESCALARES (Básicos) =====
$nomeAluno     = "Carlos";   // String: Texto. Sempre entre aspas simples ou duplas.
$anoNascimento = 1995;       // Integer (int): Número inteiro. SEM ponto.
$peso          = 75.5;       // Float: Número decimal. Use PONTO, nunca vírgula!
$matriculado   = true;       // Boolean: só true (verdadeiro) ou false (falso).

// ===== FERRAMENTAS DE INSPEÇÃO =====
echo $nomeAluno;             // Mostra o valor
var_dump($peso);             // Mostra o valor E o tipo: float(75.5)
print_r($nomeAluno);         // Parecido com echo, mas funciona melhor com Arrays
?>

Trabalhando com Strings

Strings são o tipo de dado mais usado no dia a dia de um programador web. O PHP oferece dezenas de funções nativas para manipular textos com facilidade.

PHP

<?php
$frase = "  Aprender PHP é incrível!  ";

// ===== FUNÇÕES ESSENCIAIS DE STRING =====
echo strlen($frase);              // Conta quantos caracteres tem: 28
echo strtoupper($frase);          // COLOCA TUDO EM MAIÚSCULO
echo strtolower($frase);          // coloca tudo em minúsculo
echo trim($frase);                // Remove os espaços das bordas: "Aprender PHP..."
echo str_replace("PHP", "Laravel", $frase); // Troca uma palavra por outra

echo substr($frase, 10, 3);       // Pega 3 letras a partir da posição 10: "PHP"

$nome = "Batman";
$cidade = "Gotham";

echo "O herói " . $nome . " mora em " . $cidade; // Concatenação com ponto
echo "O herói {$nome} mora em {$cidade}";         // Interpolação (mais elegante)
?>

Operadores: Matemática e Lógica

Além de calcular, os operadores definem a lógica de decisão do seu programa. Entender todos eles é fundamental.

Operadores Matemáticos e de Atribuição

PHP

<?php
$a = 10;
$b = 3;

// Matemáticos
echo $a + $b;   // 13 (Soma)
echo $a - $b;   // 7  (Subtração)
echo $a * $b;   // 30 (Multiplicação)
echo $a / $b;   // 3.333... (Divisão)
echo $a % $b;   // 1  (Módulo = RESTO da divisão. 10/3=3, sobra 1)
echo $a ** $b;  // 1000 (Potência: 10 elevado a 3)

// Atribuição Composta (Atalhos poderosos!)
$a += 5;   // Equivale a: $a = $a + 5;  → $a vira 15
$a -= 2;   // Equivale a: $a = $a - 2;  → $a vira 13
$a *= 2;   // Equivale a: $a = $a * 2;  → $a vira 26
$a++;      // Incrementa +1. Idêntico a: $a = $a + 1;
$a--;      // Decrementa -1.
?>

🔍 Por que o Módulo (%) é tão útil?

Quer saber se um número é par ou ímpar? Basta checar se o resto da divisão por 2 é zero! if ($numero % 2 === 0) significa "se não sobrar nada ao dividir por 2, é par". Esse truque é usado em listas alternadas (linhas par/ímpar com cores diferentes), paginação, geração de IDs alternados e muito mais.

Condicionais: If, Elseif, Else e Match

Toda aplicação real toma decisões o tempo todo: "Esse usuário tem permissão para ver isso?", "O estoque tem produto suficiente?". As condicionais são o mecanismo que permite ao PHP raciocinar.

A Escadinha: if / elseif / else

O PHP testa as condições de cima para baixo. Assim que encontra a primeira verdadeira, executa aquele bloco e ignora todos os outros.

PHP

<?php
$nota = 7.5;

if ($nota >= 9) {
    echo "Aprovado com Distinção! 🏆";
} elseif ($nota >= 7) {
    // Só chega aqui se a condição acima for falsa
    echo "Aprovado! ✅";
} elseif ($nota >= 5) {
    echo "Recuperação. Estude mais!";
} else {
    // Só chega aqui se TODAS as anteriores falharem
    echo "Reprovado. ❌";
}
// Com nota 7.5, imprime: "Aprovado!"
?>

🔍 Diferença entre == e === (MUITO IMPORTANTE!)

O operador == compara apenas o valor. O PHP faz uma conversão automática por baixo dos panos antes de comparar. Por isso 0 == "abc" retorna true, o que é completamente errado!

O operador === (três iguais) compara o valor E o tipo. Não há conversão. É preciso e seguro. Em código profissional, sempre use ===.

O Operador Ternário (If em uma linha)

Quando a lógica é simples (apenas dois caminhos), você pode escrever o if inteiro em uma linha só:

PHP

<?php
$idade = 20;

// Estrutura: (condição) ? "se verdade" : "se falso"
$status = ($idade >= 18) ? "Maior de idade" : "Menor de idade";
echo $status; // Imprime: "Maior de idade"

// Uso real: definir label de botão
$logado = true;
$label = $logado ? "Sair" : "Entrar";
echo "<button>{$label}</button>";
?>

O Moderno: Comando Match (PHP 8.0+)

O match é um switch evoluído. Ele compara com === (tipo e valor), retorna um valor diretamente para uma variável e lança um erro se nenhum caso bater (sem o default).

PHP

<?php
$codigoHttp = 404;

$mensagem = match($codigoHttp) {
    200, 201 => "Sucesso! Dados recebidos.",   // Vários casos na mesma linha!
    301, 302 => "Redirecionando...",
    400      => "Requisição inválida.",
    401      => "Não autorizado. Faça login.",
    403      => "Acesso proibido.",
    404      => "Página não encontrada.",
    500      => "Erro interno do servidor.",
    default  => "Código desconhecido."
};

echo $mensagem; // "Página não encontrada."
?>

Laços de Repetição: For, While, Do/While e Foreach

Loops automatizam tarefas repetitivas. Sistemas reais usam loops para renderizar listas de produtos, processar linhas de um CSV, enviar e-mails em massa ou construir tabelas HTML dinamicamente.

O For — Quando sabemos quantas vezes

PHP

<?php
// Estrutura: for (início; condição de parada; passo)
for ($i = 1; $i <= 5; $i++) {
    echo "Volta número: {$i} <br>";
}

// Exemplo real: Gerar uma tabela HTML de multiplicação
echo "<table border='1'>";
for ($n = 1; $n <= 5; $n++) {
    echo "<tr><td>{$n} x 2 = " . ($n * 2) . "</td></tr>";
}
echo "</table>";
?>

O While — Quando não sabemos quantas vezes

PHP

<?php
// Enquanto ($condicao for verdadeira), execute...
$tentativas = 0;
$senhaCorreta = "abc123";
$senhaDigitada = "errada";

while ($senhaDigitada !== $senhaCorreta && $tentativas < 3) {
    $tentativas++;
    echo "Tentativa {$tentativas}: Senha errada! <br>";
    // Num sistema real, aqui viria uma nova leitura do usuário
    $senhaDigitada = "abc123"; // Simula o usuário acertando na 2ª tentativa
}
echo "Bem-vindo!";
?>

O Foreach — O rei dos Arrays

O foreach foi criado especificamente para percorrer Arrays. Ele automaticamente pega item por item sem você precisar controlar um contador.

PHP

<?php
$produtos = ["Notebook", "Mouse", "Teclado", "Monitor"];

// Versão simples: apenas o valor
foreach ($produtos as $produto) {
    echo "Produto: {$produto} <br>";
}

// Versão completa: a chave E o valor (Essencial com Arrays Associativos)
$pessoa = ["nome" => "Ana", "idade" => 28, "cidade" => "Curitiba"];
foreach ($pessoa as $campo => $valor) {
    echo "{$campo}: {$valor} <br>";
}
?>
Break e Continue: O Freio e o Pulo
• break; — Para o laço completamente na hora. Use quando encontrar o que procurava.
• continue; — Pula o restante do código daquela rodada e vai para a próxima. Use para ignorar itens inválidos sem parar o loop.

Arrays: Listas Simples, Associativas e Matrizes

Arrays são a estrutura de dados mais poderosa do PHP. Tudo que você receber de um banco de dados, de um formulário ou de uma API externa chegará no formato de Array. Dominar Arrays é dominar o PHP.

Array Indexado (Lista Simples)

PHP

<?php
// Duas formas de criar
$frutas = array("Maçã", "Banana", "Laranja"); // Forma antiga
$frutas = ["Maçã", "Banana", "Laranja"];      // Forma moderna (preferida)

// Acessando por posição (sempre começa no ZERO!)
echo $frutas[0]; // "Maçã"
echo $frutas[2]; // "Laranja"

// Contando elementos
echo count($frutas); // 3

// Adicionando um novo item ao final
$frutas[] = "Uva";
echo count($frutas); // Agora é 4
?>

Array Associativo (Chave → Valor)

Em vez de posições numéricas, cada slot tem um nome descritivo. É a estrutura que representa registros de banco de dados.

PHP

<?php
$produto = [
    "id"       => 1,
    "nome"     => "Notebook Dell",
    "preco"    => 3500.00,
    "estoque"  => 15,
    "ativo"    => true
];

// Acesso por chave
echo "Produto: " . $produto["nome"];
echo "Preço: R$ " . $produto["preco"];

// Modificando um valor
$produto["preco"] = 3200.00;

// Verificando se uma chave existe
if (array_key_exists("estoque", $produto)) {
    echo "Temos " . $produto["estoque"] . " unidades.";
}
?>

Array Multidimensional (Matriz)

É uma lista de Arrays. Isso simula exatamente o que uma tabela de banco de dados retorna: várias linhas, cada uma com várias colunas.

PHP

<?php
// Imagine isso como uma tabela "usuarios" do banco de dados
$usuarios = [
    ["id" => 1, "nome" => "Alice",  "email" => "alice@mail.com", "admin" => true ],

?>

Funções Nativas de Arrays

O PHP vem de fábrica com mais de 70 funções para manipular Arrays. Conhecer as principais poupa centenas de linhas de código.

PHP

<?php
$numeros = [5, 3, 8, 1, 9, 2, 7];
$nomes   = ["Carlos", "Ana", "Bruno", "Zara"];

// ===== ORDENAÇÃO =====
sort($numeros);         // Ordena do menor para o maior (modifica o original)
rsort($numeros);        // Ordena do maior para o menor
asort($nomes);          // Ordena mantendo as chaves associativas
ksort($nomes);          // Ordena pelas chaves

// ===== BUSCA =====
$pos = array_search("Ana", $nomes); // Retorna a chave onde "Ana" foi encontrada
$existe = in_array("Ana", $nomes);  // Retorna true ou false

// ===== TRANSFORMAÇÃO =====
$precos   = [100, 200, 150, 300];
$comDesconto = array_map(fn($p) => $p * 0.9, $precos); // Aplica 10% de desconto em todos
$caros       = array_filter($precos, fn($p) => $p > 150); // Filtra só os acima de 150
$total       = array_sum($precos);  // Soma todos: 750
$maximo      = max($precos);        // Maior valor: 300
$minimo      = min($precos);        // Menor valor: 100

// ===== MANIPULAÇÃO =====
array_push($nomes, "Diego");  // Adiciona ao final
array_pop($nomes);            // Remove do final
array_shift($nomes);          // Remove do início
$fatias = array_slice($nomes, 1, 2); // Pega 2 itens a partir do índice 1
$merged = array_merge([1,2], [3,4]); // Junta dois arrays: [1,2,3,4]

print_r($comDesconto);
?>

Funções, Escopo, Tipagem e Arrow Functions

Funções são o pilar da reutilização de código. Em vez de copiar e colar o mesmo bloco 10 vezes, você escreve a lógica uma vez, dá um nome e invoca quantas vezes precisar.

Criando e Usando Funções

PHP

<?php
// Função simples com retorno
function saudar(string $nome): string {
    return "Olá, {$nome}! Bem-vindo.";
}
echo saudar("Felipe"); // "Olá, Felipe! Bem-vindo."

// Parâmetro com valor padrão (opcional)
function calcularDesconto(float $valor, float $taxa = 0.10): float {
    return $valor - ($valor * $taxa);
}
echo calcularDesconto(200);       // Usa taxa padrão 10%: 180
echo calcularDesconto(200, 0.25); // Taxa de 25%: 150

// Tipagem de retorno (PHP 7+) garante que a função sempre devolva o tipo correto
function dobrar(int $num): int {
    return $num * 2;
}
?>

🔍 O Escopo da Caixa Preta

Variáveis criadas dentro de uma função só existem lá dentro. Código de fora não as enxerga. Da mesma forma, variáveis criadas fora da função não entram automaticamente. A única saída é o return. Isso é chamado de Escopo e evita que funções diferentes sobrescrevam acidentalmente as variáveis umas das outras.

Arrow Functions (Funções de Seta)

Uma sintaxe curta, moderna e elegante para funções de uma linha. Muito usada junto com array_map e array_filter:

PHP

<?php
// Função normal
function triplicar($n) { return $n * 3; }

// Arrow Function equivalente (muito mais curta!)
$triplicar = fn($n) => $n * 3;
echo $triplicar(10); // 30

// Uso prático com array_map
$precos = [100, 200, 300];
$comImposto = array_map(fn($p) => $p * 1.12, $precos);
// Resultado: [112, 224, 336]
print_r($comImposto);
?>

<?php
$erros  = [];
$sucesso = "";

}
?>

Ponte para o Laravel: Request e Validation

No Laravel, toda essa validação manual vira apenas algumas linhas elegantes:
$request->validate(['nome'=>'required', 'email'=>'required|email', 'idade'=>'min:18']);
O Laravel lança os erros automaticamente de volta para a tela, preenchendo as mensagens de erro sem você escrever nenhum if.

Sessões e Cookies: Memória entre Páginas

O PHP por si só é "sem memória". Cada vez que você carrega uma página, o PHP começa do zero. Mas um site de verdade precisa lembrar que você está logado! Para isso usamos Sessões e Cookies.

Sessão vs Cookie: Qual a diferença?
• Sessão ($_SESSION): Os dados ficam guardados no servidor. Mais seguro. Dura enquanto o navegador estiver aberto (ou até você chamar session_destroy()).
• Cookie ($_COOKIE): Os dados ficam guardados no navegador do usuário. Menos seguro (pode ser manipulado). Útil para "Lembrar de mim", preferências de idioma, etc.

Trabalhando com Sessões

PHP

<?php
// OBRIGATÓRIO: session_start() deve ser a PRIMEIRA linha de todo arquivo que usa sessão
session_start();

// ===== SALVAR DADOS NA SESSÃO (ex: após o login) =====
$_SESSION["usuario_id"]   = 42;
$_SESSION["usuario_nome"] = "Felipe";
$_SESSION["logado"]       = true;

// ===== VERIFICAR SE O USUÁRIO ESTÁ LOGADO (em outra página) =====
if (!isset($_SESSION["logado"]) || $_SESSION["logado"] !== true) {
    header("Location: login.php"); // Redireciona para o login
    exit(); // Para a execução do script!
}

echo "Bem-vindo, " . $_SESSION["usuario_nome"] . "!";

// ===== LOGOUT (Destroi a sessão completamente) =====
// session_destroy();
?>

Trabalhando com Cookies

PHP

<?php
// Criando um Cookie (deve ser feito ANTES de qualquer echo ou HTML!)
// setcookie(nome, valor, tempo_de_expiração_em_segundos)
$tempoCookie = time() + (30 * 24 * 60 * 60); // 30 dias
setcookie("idioma_preferido", "pt-BR", $tempoCookie);
setcookie("tema",             "escuro", $tempoCookie);

// Lendo um Cookie
if (isset($_COOKIE["idioma_preferido"])) {
    $idioma = $_COOKIE["idioma_preferido"];
    echo "Idioma definido: {$idioma}";
}

// Deletando um Cookie (define o tempo de expiração no passado)
setcookie("idioma_preferido", "", time() - 3600);
?>

Include, Require e Arquitetura de Arquivos

Um projeto real tem dezenas ou centenas de páginas. O cabeçalho, o rodapé e a conexão com banco de dados são os mesmos em todas elas. Em vez de copiar e colar esse código em cada página, criamos arquivos separados e os importamos.

PHP — Estrutura de Arquivos

<?php
// ===== INCLUDE vs REQUIRE =====
// Se o arquivo NÃO for encontrado:
include 'banner_promo.php';  // ⚠️ Aviso amarelo, mas o site continua
require 'conexao.php';       // ❌ Erro FATAL, site trava imediatamente

// ===== _ONCE: Evita inclusão duplicada =====
require_once 'conexao.php';  // Se já foi incluído antes, ignora silenciosamente
include_once 'funcoes.php';  // Mesmo comportamento

// ===== EXEMPLO DE USO REAL em index.php =====
require_once 'config/conexao.php';  // Conexão com o banco
require_once 'includes/funcoes.php'; // Funções reutilizáveis

include 'partials/header.php'; // Cabeçalho HTML

echo "<main>Conteúdo principal da página aqui!</main>";

include 'partials/footer.php'; // Rodapé HTML
?>

O Domínio do Banco de Dados

A etapa que separa sites estáticos de sistemas reais.

PDO: O Padrão Ouro de Conexão

Antigamente usava-se `mysql_connect()`, depois `mysqli`. Hoje, o padrão global da indústria é o PDO (PHP Data Objects). O PDO é incrível porque ele consegue conversar com 12 tipos diferentes de bancos (MySQL, PostgreSQL, SQLite, Oracle) mudando apenas 1 linha de código!

🔍 Try / Catch (Tratamento de Exceções)

A conexão com o banco é a coisa mais sensível de um site. O servidor MySQL pode cair. A senha pode mudar. Em vez de deixar seu site vomitar um erro vermelho gigante para o cliente, "envolvemos" a tentativa de conexão num bloco try (Tente). Se explodir algum erro, o PDO lança uma "Exceção", e o bloco catch (Capture) entra em ação para lidar com o problema de forma silenciosa e elegante.

PHP

<?php
$host = "localhost";
$db_name = "curso_php";
$user = "root";
$pass = ""; 

try {
    // 1. Criamos a string de DSN (Data Source Name)
    $dsn = "mysql:host={$host};dbname={$db_name};charset=utf8";
    
    // 2. Instanciamos o objeto PDO
    $pdo = new PDO($dsn, $user, $pass);
    
    // 3. Forçamos o PDO a lançar Exceções caso algo dê errado em Queries futuras
    $pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
    
    echo "Banco Online!";
} catch (PDOException $e) {
    // Se a senha estiver errada, a execução do "try" é abortada e pula direto pra cá!
    // Num sistema real, gravaríamos isso num Log em vez de mostrar na tela.
    die("Falha Catastrófica: " . $e->getMessage());
}
?>

CRIAR (Insert): O Segredo do Prepare

Ao inserir dados vindos de um formulário preenchido por um humano na internet, você nunca, sob nenhuma hipótese, coloca a variável do usuário diretamente no comando SQL. Isso abre brecha para o hacker deletar seu banco inteiro.

A técnica para inserir com segurança máxima chama-se Prepared Statements.

PHP

<?php
// Dados vindo de um formulário hipotético (já sabemos que estão aqui)
$nomeCliente = "Maria Sousa";
$emailCliente = "maria@email.com";

// 1. Escrevemos a Query, mas colocamos ? nos espaços vagos (Proteção máxima)
$sql = "INSERT INTO usuarios (nome, email) VALUES (?, ?)";

// 2. Preparamos o comando no banco (O banco checa a estrutura)
$stmt = $pdo->prepare($sql);

// 3. Executamos enviando um Array. O PDO substitui a 1ª interrogação pelo 
// primeiro item do array, e a 2ª pelo segundo item, limpando os textos contra hacks!
$stmt->execute([$nomeCliente, $emailCliente]); 

echo "Cadastrado com sucesso no banco!";
?>

LER (Select): Fetch vs FetchAll

Existem duas formas de pegar dados. Você quer apenas UM cliente (ex: Ver Perfil), ou quer TODOS os clientes (ex: Relatório de Vendas)?

PHP

<?php
// ============================================
// CASO 1: Pegando TODOS os usuários (fetchAll)
$sqlGeral = "SELECT id, nome FROM usuarios";
$stmtGeral = $pdo->query($sqlGeral);

// Puxa uma MATRIZ (Array de Arrays)
$listaInteira = $stmtGeral->fetchAll(PDO::FETCH_ASSOC);

foreach ($listaInteira as $linha) {
    echo "ID: {$linha['id']} | Nome: {$linha['nome']} <br>";
}

// ============================================
// CASO 2: Pegando UM único usuário com base no ID (fetch)
$idBuscado = 5;
$sqlUnico = "SELECT email FROM usuarios WHERE id = ?";
$stmtUnico = $pdo->prepare($sqlUnico);
$stmtUnico->execute([$idBuscado]);

// Puxa apenas um Array Simples (uma linha do banco)
$usuarioUnico = $stmtUnico->fetch(PDO::FETCH_ASSOC);

// Verifica se achou alguém
if ($usuarioUnico) {
    echo "E-mail achado: " . $usuarioUnico['email'];
} else {
    echo "Usuário com ID 5 não existe!";
}
?>

ATUALIZAR (Update): A Regra de Ouro do WHERE

O UPDATE serve para mudar uma informação que já existe. (Ex: Mudar a senha). A regra de ouro de banco de dados é: O UPDATE precisa obrigatoriamente de uma condição WHERE (Onde).

O clássico desastre
Se você fizer UPDATE usuarios SET senha = 123 sem o WHERE, o banco vai alterar a senha de ABSOLUTAMENTE TODOS os usuários do seu sistema para 123 de uma vez só! Fim do sistema. Sempre diga QUAL usuário sofrerá o Update usando WHERE id = X.
PHP

<?php
$novoEmail = "maria_nova@email.com";
$idDaMaria = 1;

// "Atualize a tabela usuários, definindo o email para X, MAS APENAS ONDE o id for Y"
$sql = "UPDATE usuarios SET email = ? WHERE id = ?";

$stmt = $pdo->prepare($sql);
$stmt->execute([$novoEmail, $idDaMaria]);

// Podemos descobrir quantas linhas foram alteradas com isso:
$linhasAlteradas = $stmt->rowCount();
echo "Total de perfis atualizados: " . $linhasAlteradas;
?>

DELETAR (Delete): Limpeza Segura

Idêntico ao Update. Se esquecer o WHERE, você apaga a tabela inteira e sua carreira junto com ela.

PHP

<?php
$idDoUsuarioASerExcluido = 10;

$sql = "DELETE FROM usuarios WHERE id = ?";
$stmt = $pdo->prepare($sql);

if ($stmt->execute([$idDoUsuarioASerExcluido])) {
    echo "Usuário excluído para sempre.";
}
?>

Ponte para o Laravel: Eloquent Substituto

Nós aprendemos os comandos brutos: INSERT, SELECT, UPDATE, DELETE. É extremamente importante entender a lógica deles. Mas no Laravel, você faria toda essa seção inteira com simples comandos orientados a objeto.
Exemplo de Insert no Laravel: Usuario::create(['nome'=>'Maria', 'email'=>'x@x.com']);
Exemplo de Select: $usuario = Usuario::find(5);
Exemplo de Update: $usuario->update(['email' => 'novo@x.com']);
Exemplo de Delete: $usuario->delete();

Classes, Objetos e a Visibilidade (Encapsulamento)

O nível profissional não aceita dezenas de funções soltas num arquivo. Nós empacotamos propriedades e funções relacionadas dentro de Classes.

🔍 O Conceito de Public e Private

Quando você diz que a propriedade $saldo de uma Conta Bancária é `public` (Pública), qualquer pessoa programando no sistema pode fazer $conta->saldo = -10000; de fora da classe, quebrando a regra de negócio.
Por isso, usamos `private` (Privada). Assim, a variável só pode ser mexida por dentro da própria classe. Nós obrigamos o programador de fora a usar um método público controlado (como o método sacar()), que antes de tirar o dinheiro, vai fazer um `if` para checar se o cara tem saldo suficiente.

PHP

<?php
class Conta {
    // Só a própria classe pode mexer aqui dentro
    private $saldo = 0; 
    
    // Método público (A porta de entrada controlada)
    public function depositar($valor) {
        if ($valor > 0) {
            $this->saldo += $valor;
        }
    }
    
    // Getters: O único jeito de quem está de fora conseguir "Ler" o saldo
    public function verSaldo() {
        return $this->saldo;
    }
}

$minhaConta = new Conta();
$minhaConta->depositar(500);
// $minhaConta->saldo = 9999999; <-- ISSO DARÁ UM ERRO FATAL! É PRIVADO!
echo "Meu saldo real é: " . $minhaConta->verSaldo();
?>

Herança e Construtores (A Base dos Frameworks)

Um dos maiores poderes da POO é a reutilização violenta de código através da Herança (`extends`). O Construtor garante que o objeto já "nasça" do jeito certo.

PHP

<?php
class Inimigo {
    protected $vida; // 'protected' é como private, mas os 'filhos' podem mexer!
    
    public function __construct($vidaInicial) {
        $this->vida = $vidaInicial;
        echo "Um inimigo surgiu com {$this->vida} HP!<br>";
    }
    
    public function sofrerDano($dano) {
        $this->vida -= $dano;
    }
}

// O Chefão HERDA tudo que o Inimigo comum tem, e adiciona seus próprios golpes!
class Chefao extends Inimigo {
    public function ataqueEspecial() {
        echo "O Chefão jogou fogo!<br>";
    }
}

// O Construtor exige o HP na hora de criar (new)
$boss = new Chefao(5000); 
$boss->sofrerDano(100); // Ele herdou o método de sofrer dano!
$boss->ataqueEspecial(); // Ele tem o ataque exclusivo dele!
?>
